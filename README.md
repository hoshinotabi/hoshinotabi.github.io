# 藏スキャン v0.2.0（GitHub Pages 用）

バーコードを読んでリストに積み、まとめて藏のアプリ（GAS）へ渡すための画面です。
登録と重複の確認は GAS 側で行います。この画面は鍵を持ちません。

## 公開してよいもの／いけないもの
- 公開してよい：この index.html（鍵・URL・ホスト名は入っていません）
- 置かない：Notion のトークン、楽天のアプリ ID、GAS の URL、NAS や Tailscale の名前、スクリーンショット
- GAS の URL は各端末の設定（歯車）から入れます。端末の中にだけ保存されます。
- リポジトリの履歴に一度でも秘密を入れたら、消すのではなく「鍵を作り直す」が正解です。

## 置き方
1. 新しいリポジトリ（例：kura-scan）の同じ階層に index.html・manifest.webmanifest・icon-180.png・icon-192.png・icon-512.png を置き、Settings → Pages で公開。
2. iPhone の Safari で開き、歯車 → 送り先に GAS の /exec URL を保存。
3. ホーム画面に追加するとアプリのように使えます。

試験用のバーは、手元でファイルを開いたときか、URL の末尾に ?dev を付けたときだけ出ます。

## 公開前に一度だけ：読み取り部品の改ざん対策
外部から読み込む ZXing がすり替えられていないかを、指紋で確かめる設定です。Mac のターミナルで：

    curl -sL https://cdn.jsdelivr.net/npm/@zxing/library@0.18.6/umd/index.min.js | openssl dgst -sha384 -binary | openssl base64 -A

出た文字列の頭に sha384- を付けて、index.html の ZX_SRI = '' の中に入れます。

## GAS へ渡すもの
「藏へ送る」で GAS を ?batch=（JSON を base64url 化）付きで開きます。

    { "v":1, "items":[ { "i":"9784101010014", "s":"積読", "o":"紙のみ", "t":"タグ", "m":"メモ" } ] }

GAS 側（v1.0 で実装）は、書誌の取得 → 藏 DB との重複確認 → 一覧で確認 → 登録、の順に処理します。
内容はすべて「入力」として扱い、ISBN の形と選択肢の名前を GAS 側でもう一度確かめます。

## ホーム画面に追加して使うとき（v0.2）
- Safari の共有 →「ホーム画面に追加」。全画面で開き、ノッチと下端まで帯の色で塗ります。
- ホーム画面のアプリは Safari と保存領域が別です。送り先は追加後にもう一度だけ保存してください。
- GAS へ送ったときの Google ログインも、アプリの中で初回だけ求められることがあります。
